# Detials


**Armored mechanoids: Some basic work mechanoids with strengthened armor have the ability to throw grenades and release warurchins. These basic technology level mechanoids can give you advantages in the early stage

Weapon under test: a kind of weapon in the industrial era, which can be regarded as the predecessor of electric weapons to some extent, and can be used as a LGIS missile launcher.

Armor: a bulletproof vest that can throw random grenades, and a compound cloak that can make users invisible

If you got all dlc and install *vanilla expanded framework*, you will unlock a challenging scenario, playing the role of two hungry refugees living in an abandoned county.
